### Post #2 — @ErgoWallet (2021-05-19)

To create Ergo wallet offline you

1. Download latest Ergo Wallet Desktop for your Operating system from [Releases · ErgoWallet/ergowallet-desktop · GitHub](https://github.com/ErgoWallet/ergowallet-desktop/releases).
2. Verify the signature of the file.
3. Create new seed phrase and backup it
4. Use addresses generated in wallet.
