### Post #1 — @Martin-mx (2019-12-04)

This minor release includes:

* new API method /script/executeWithContext to reduce a script (to a cryptographic protocol) according to given context (PR [#917](https://github.com/ergoplatform/ergo/pull/917) )
* test for a new version of ergo + sigma on the mainnet/testnet (PR [#925](https://github.com/ergoplatform/ergo/pull/925) )
* AVL-IODB and ergo-wallet are now sub-projects of the Ergo (with separate publishing) (PR [#944](https://github.com/ergoplatform/ergo/pull/944), PR [#968](https://github.com/ergoplatform/ergo/pull/968) )
