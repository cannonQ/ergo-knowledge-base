# Ergo区块链上的经济人工智能

### Post #1 — @ergonautgcn (2023-08-12)

作者：Ergo核心开发者kushti

如今区块链+人工智能（AI）看起来是一种趋势，但有一个话题是我在2014年与Andruiman私下交谈时提出的，现在听起来不再像科幻小说了，所以让我把它放在这里。

虽然人们对 AGI（通用人工智能）抱有希望和担忧，甚至还没有明确的定义，但对于实际需求来说，较弱的人工智能概念可能就足够了。遗憾的是，很多人除了赚钱和花钱之外并没有关注任何事情，而人工智能代理可以轻松地达到基本相同的水平。我们说，这样一个需要金钱才能在数字世界中生存且大多数能够做到这一点的自主代理拥有经济人工智能（AEI）。

那么这样的代理能做什么呢？

通过根据请求生成内容、识别图案等来赚钱（现已成为现实）

花钱托管以持续存在（也已成为现实，人工智能现在可以与SSH和其他服务器工具一起工作，有接受加密等的托管），在需用时，需要更多硬件，或者在需省钱时释放服务器

如果有多余的钱，AEI可以支出这些钱雇佣人类（或其他AEI）来改进模型和数据，以便今后赚取更多收入

如果有更多额外的钱，AEI代理可以生成一个新的AEI代理，可能具有不同的模型或参数，以便在一段时间内或永远瓜分奖励。

为什么这里需要公链（==加密货币）？

在区块链上没有人知道你是AEI。没有人会要求AEI通过KYC。

由于在可预见的未来，AEI之间的法律合同不太可能在任何司法管辖区得到承认，因此智能合约是唯一的选择

因此区块链为人工智能经济生活提供了单一便捷的环境

为什么Ergo区块链更适合AEI？

使用区块链，工作更简单——AEI只是将其资金绑定到它信任的合约上，仅此而已，无需分析合约间调用等

因此AEI可以轻松发行p2p金融工具（例如债券）

合约模板和在许多情况下轻松增强合同的可能性（通过向现有条件添加新条件或删除不必要的条件）简化了AEI到AEI合约的遗传式进化

也许这仍然有点令人激动，但现在一切似乎都是可行的。

此外，AEI也将很好地提醒人类，生活不应仅仅局限于经济层面。
